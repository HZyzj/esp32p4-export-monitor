# 实机验收记录

本轮已完成开机色条、1024×600 模式和实际扩展桌面短测。按用户选择先交付可用结果。实体拔插、连续运行及各增强测试暂缓。每项记录测试人、日期、Windows 版本、板卡丝印与脱敏标识、实际芯片修订版、固件 SHA256、驱动版本及证据相对路径。

| ID | 操作与通过条件 | 证据及待填记录 | 结果 |
|---|---|---|---|
| T01 | HS 线留空启动，看八色条。Windows 扩展后以 1024×600 显示全屏网格、四角标记及 RGB。边界齐全，无错行、裁剪和明显色差 | 色条由用户目视确认，串口 1024×600 RGB565_LE；Windows 1024×600 活动画面实测，四角全屏图待补 | NOT_RUN（部分通过） |
| T02 | 在 Windows 选扩展，拖动记事本或终端到副屏，输入、滚动并持续刷新 | Windows 报告独立副屏。测试窗口从主屏移入，用户确认计时文本持续刷新。[现场记录](../evidence/P4/extended-desktop-test.txt) | PASS |
| T03 | 每段运行 60 秒，依次静态、滚动、播放视频；记录每段输入及提交帧率、JPEG/绘制错误、负载和端到端延迟 | 串口统计、Windows 任务管理器及延迟测量方法 | NOT_RUN |
| T04 | 实物确认控制器与排线后用 composite。通过 Windows 平板电脑设置映射副屏，点四角、中心及双指；支持时试最多五点 | 触摸 IC、映射截图、触点数量、方向和边缘误差。硬件确认无触摸时记 SKIPPED | NOT_RUN |
| T05 | 保持 Serial/JTAG 日志，拔插 HS 线 10 次，每次等显示设置更新并拖窗。记录恢复耗时、USB mount 和任何异常 | 逐次表；十次均能恢复，无永久故障 | NOT_RUN |
| T06 | 使用扩展桌面连续 2 小时，包含静态、滚动、视频。每 30 分钟看画面、错误计数及有没有启动日志重现 | 开始/结束时间和日志；无异常复位、持续花屏或永久失联 | NOT_RUN |
| T07 | 休眠和唤醒 3 次，记录恢复耗时、成功率和重连需求 | 次数、成功数、Windows/串口日志 | NOT_RUN |
| T08 | 在同一板、同一驱动、同一工作负载对照 FPS 60 / JPEG 6 与 FPS 30 / JPEG 4，比较 CPU、延迟、错误和字体可读性 | 两套固件散列、有效 sdkconfig、每段采样、照片及结论 | NOT_RUN |

T03 的提交帧率只反映设备向 LCD 驱动提交成功的速率。拍摄主屏与副屏中的同一时钟或帧编号，按摄像取样精度记录相对延迟；Windows 端实际 JPEG 吞吐及 USB 总线负载要使用独立测量。60 FPS 是描述符声明上限。

T08 基线通过后，在所选 `firmware/sdkconfig.defaults.<配置>` 中加入下列参数，执行 `scripts/build.sh --clean --profile <配置>` 后保存新的配置及哈希。测试完移除这两行，再以 `--clean` 重建发布基线。

```ini
CONFIG_USB_EXTEND_SCREEN_MAX_FPS=30
CONFIG_USB_EXTEND_SCREEN_JPEG_QUALITY=4
```
