# 决策记录

| 决策 | 依据 |
|---|---|
| 采用当前 WSL ext4 目录 | 任务书在该目录。原目录没有可用 Git 元数据。保留任务书，使用上游 Git checkout 和独立构建工作树 |
| 锁定官方示例 master 的当时 HEAD 和 ESP-IDF v5.4.4 | 示例需要 `>=5.4.4,!=5.5.0,!=5.5.1,!=5.5.2`。现有 IDF commit 在 v5.4.2 之后，原 Python 3.10 虚拟环境通过重定向链接执行 3.11。新的 IDF、必要工具及 venv 放在项目中，原 SDK 和系统路径保留 |
| 旧定义加 V1.6 amend | 43 项板卡列表中无本型号专用定义。核对 LCD 连接、电源、Flash 和 PSRAM 后单独约束。删除生成表里的闲置设备以排除 GPIO35 冲突 |
| 先交付纯显示版，同时构建复合版 | 优先建立 LCD 和 USB 显示链路。纯显示只暴露 Vendor 0x2987，复合使用 0x2986，保留触摸和音频的后续测试入口 |
| 复用 JPEG、传输及面板驱动 | 小补丁只约束依赖、使用已有 DPI framebuffer 加开机色条、记录复位及 PSRAM、USB 速度和每五秒帧结果 |
| 暂停安装当前 IDD | Windows 只读验证结果显示安装器 Valid、目录 UnknownError；内部脚本会调用测试证书。待乐鑫提供现有 Windows 信任策略认可的发布包 |
| 兼容已安装的 Windows IDD 产品字符串读取路径 | 在保留 Vendor 接口字符串的同时，USB 产品字符串也提供相同模式参数。帧长度通告按驱动 KiB 约定向下取整。实机从 320×240 回退模式恢复至 1024×600 |
